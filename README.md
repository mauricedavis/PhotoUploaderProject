# PhotoUploaderProject
Work based on efforts at CollegeTrack to create a simple photo uploader LWC that replaces their 'old' functionality.
1. Allow drag-n-drop or file upload of photo/image.
2. Immediate rendering of the photo/image after 'done'.
3. Allow drag-n-drop over another photo/image to 'replace' original image.
4. Use 'Is Currently Displayed' field on ContentVersion object to enforce single photo/image displayed on-screen
